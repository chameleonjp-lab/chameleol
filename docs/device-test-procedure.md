# iPhone での確認手順

2026年11月11日時点の手順です。ここまでの確認は、自動ブラウザ（パソコン上の Chromium）で行いました。iPhone の Safari ではまだ確かめていません。自動ブラウザの結果と iPhone の結果は分けて記録します（自動ブラウザの結果は `docs/acceptance/results.md`）。

## 準備

パソコンと iPhone を同じ Wi-Fi につなぎます。パソコンで次を実行すると、検証用のゲームが作られて、同じ Wi-Fi の端末から開けるようになります。

```sh
npm ci
npm run build
node scripts/serve.mjs --root dist --host 0.0.0.0 --port 5173
```

iPhone の Safari で `http://<パソコンのIPアドレス>:5173/` を開きます。この形では順位の通信先がないため、名前の登録や順位は「つながっていない」表示になります。通信まで試す時は、検証用の Supabase を用意して `KAMEREORU_API` を指定して作り直します（`docs/release/release-and-rollback.md` の「1. 検証環境で通す」）。

ホーム画面の下にある「検証メニュー」を使うと、20棟目の手前、終了の手前、夜の場面から始められます。50棟を毎回はじめから遊ばなくても、明るさの解放やクリアの演出を確かめられます。このメニューは本番用には出ません。

## 確かめること

計画書 P9 の項目を、次の5つのまとまりに分けて試します。結果は下の記録表に書きます。

1. **画面の形**：縦向きと横向き、短い縦の画面（402×700 に近い大きさ）、アドレスバーが伸び縮みした時、画面の上下の切り欠き（安全領域）で、パレット・明るさのバー・警戒の表示が隠れたり重なったりしないか。15言語のうち長い訳（ドイツ語、ロシア語など）でも文字があふれないか。
2. **指の操作**：2本の指でパレットとバーを同時に動かせるか。片方を離してももう一方が続くか。指を置いてから色が変わるまでの遅れが気にならないか。画面のスクロールや拡大が起きないか。
3. **色の見え方**：壁と体の色が同じ値の時、iPhone の画面でも同じ色に見えるか。一致度85%（色差6）と55%（色差14）の境目が、「同じ／少し違う／明らかに違う」の感覚と合うか。暗い色と白に近い色で、合わせられるのに失敗と判定される組がないか。
4. **中断と保存**：ホームへ戻る、着信、画面を消す、別のアプリへ切り替える、Safari を強制終了する、通信を切る。それぞれの後で「つづきから」が保存した時点から再開できるか。音が止まり、戻った時に鳴り直すか。
5. **長く遊ぶ**：3回続けて遊んだ時に、読み込みが遅くならないか、本体が熱くならないか、画面がかくつかないか。

## 測って記録する値

追加演出80件の確認は `docs/acceptance/effects80-evidence.md` の各No.へ記録します。検証版の強制表示で開始・中間・終了を確認し、採用80件と除外20件を混ぜません。402×700、402×874、874×402でガイド4段階・結果・19→20棟・46→50棟の画面を保存し、パレット・バー・停止が押せることも確認します。

iPhone 17 Pro Safariでは、装飾あり／なしを同じseed・入力・温度条件で比べます。ウォームアップ後、開始直後と最終地区を各30秒録画・計測し、フレーム間隔の中央値と95百分位を残します。目標は95百分位33.4ms以下、装飾ありの中央値悪化10%以内です。基準版自体が目標を超えた場合は両方の値を残して合格を保留します。10回連続の再プレイで描画物体数と購読・予約・古い画面への更新を確認します。SafariでJSヒープが取れない場合は「未測定」と書き、物体数をヒープの値に置き換えません。自動Chromiumの数値は実機の合格根拠にしません。

| 値 | 測り方 | 記録 |
| --- | --- | --- |
| 初めて開いた時の読み込み時間 | Safari の履歴とデータを消してから開き、ホームが出るまでの秒数 | 未測定 |
| 操作の遅れ | 指を動かしてから色見本が変わるまでを、画面録画のコマ送りで数える | 未測定 |
| 保存の間隔 | 遊んでいる途中で強制終了し、再開した時に何秒戻ったか | 未測定 |
| 操作履歴の最大の大きさ | 検証メニューの結果画面、または送信した記録の大きさ | 未測定 |
| 発熱・描画のかくつき | 3回連戦の後の本体の温かさ、かくつきの有無（主観でよい） | 未測定 |
