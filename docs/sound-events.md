## 守っていること

最初に有効な保存がない時は、音はオンで、控えめな音量（音楽45%・効果音70%・環境音35%）から始めます。保存した「0」や「消音」は有効な設定として残し、未設定と取り違えません（`sanitizeAudioSettings`）。消音を解除すると、設定済みの音量に戻ります。

音声の準備は、開始・再開・ボタンなどの明示的な操作の中で行います。ホームなど本編の外では、画面に触れた時に準備してホームの曲を流します。停止中は「再開」を押すまで準備しません。音を出せない端末でも、ゲーム・得点・保存は止まりません。停止や画面離脱では音を止め、予定していた音を捨てるので、復帰したときに過去の足音や警告がまとめて鳴ることはありません。停止中に音量を変えても、本編の音楽は再開しません。

音だけで答えが分かる作りにはしていません。警戒の段階は、ゲージの長さと言葉、警察の人数でも伝えます。本編の曲の変化（ドラムが増える・調が上がる）と心拍は雰囲気づけで、得点や判定には関わりません。

## 試聴について

この表はコードの確認に基づくものです。曲と効果音は楽譜と数式から作っており、作った時点では誰も実際の音を聞いていません。音量のつり合い、旋律が耳に心地よいか、心拍や笛がうるさすぎないかは、実機で聞いて直す必要があります。自動の試験（`tests/audio/mixer.test.mjs`）で確かめたのは、「すべての出来事に音がある」「鳴らしても失敗しない」「停止の後は鳴らない」ことだけです。iPhone の実機での試聴（聞き分けられるか、うるさすぎないか、消音スイッチとの関係）はまだ行っていません。結果は `docs/acceptance/results.md` の SOUND-01／02 に記録します。

## ボーナス得点（v3/v4）

`src/presentation/bonus-audio.js` の `choosePassCue` は、その更新の通過・次棟・ガイド・警告の候補を集め終わった後に1つだけ選びます。優先は発見／クリア、ガイド／解放／危険、複数／到達ボーナス、単独ボーナス、従来の到達／連続成功／通過です。見送った音は保存・再生予約をせず、再開・言語変更・結果再表示・サーバー訂正でも再発音しません。

| 確定した獲得 | mixerイベント | 合成音 |
| --- | --- | --- |
| 精密 +5 / +10 | `bonusPrecision` (`tier:5/10`) | 澄んだ1音／2音 |
| 安定 | `bonusSteady` | 穏やかな短い和音 |
| 10棟区切りの通過 | `bonusMilestone` | 上昇する3音 |
| 素早い色合わせ | `bonusQuick` | 短い風切り音と1音 |
| 複数を同時獲得 | `bonusMulti` | 1つの短い上昇音と和音 |
| 全棟成功でクリア | `bonusAllSuccess` | 既存clearと一体の終止音。clearとの二重呼出しなし |

既存AudioContext、効果音バス、消音、音量0、発音上限、背景音を下げる処理を共有します。音声が利用できない場合も得点・文字表示は同じです。
