# 残る演出2件の実装計画

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** No.37の交互表示とNo.85の初クリア切符を完成させ、レビューできるPRにする。

**Architecture:** 既存の警察の表示状態、端末内の初クリア判定、結果画面の部品を使う。結果画面に渡す一時的な情報へ初クリア日時を加え、既存の言語設定で日付を表示する。

**Tech Stack:** JavaScript、Three.js、HTML/CSS、Nodeの試験、既存のPlaywright試験。

**Spec:** ../specs/2026-11-11-chameleol-effects80-spec.md（No.33・37・85）。2026-11-13の本人指示「現行計画に残る2件を実装」に基づく。

## Global Constraints

- 対象は似顔絵と双眼鏡の交互表示、初クリア切符の2件。
- 警察1人・猶予中・直前成功という条件、ほかの警察動作の優先、同じ猶予で1回の条件を保つ。
- 似顔絵は1秒、双眼鏡は0.8秒。停止・再開で順番を進めず、新しいプレイで似顔絵から再開する。
- 旧仕様の「似顔絵は1プレイ1回まで」は、No.37の交互表示と両立しない。今回の交互表示に合わせ、表示できた場面ごとに似顔絵→双眼鏡を繰り返す条件へ統一する。
- 初クリア日と判定は既存の端末保存を使う。保存キー、データベース版、得点・判定・送信形式を変えない。
- 切符は初クリアの結果にだけ表示する。日時不明なら架空の日付を補わない。文言は既存の15言語、日付は選択言語で表示する。
- 402×700、402×874、874×402、動きを減らす設定に対応する。
- mainへ直接反映せず、マージ・本番公開・実験場連携は行わない。

## Review Focus

- 無線・急停止に表示を遮られた場合、交互の順番を消費しない。
- 同じ猶予や停止・再開で小道具を二重表示しない。
- 初回終了の日時を結果画面まで保ち、言語変更・2回目のクリアで日付を変えない。
- 日時が不正・欠損の古い結果でも、結果全体を壊さず今日の日付を捏造しない。
- 日付や長い翻訳が切符から横にはみ出さず、再プレイ操作を妨げない。
