# ② カメレオる：ChatGPT実装計画書

2026-11-16。親計画は[①全体実装計画書](2026-11-16-chameleol-master-plan.md)、正本は[全体要件](../specs/2026-11-16-chameleol-final-requirements.md)。単独で別の仕様を決めない。目標は、既存の#23処理を使ってClaudeの画面を通常起動へ接続し、全体合格・PR後の問題解消・確認候補までを終えること。

## 担当と優先順位

CG-O：gpt-6.1-sol/high、CG-S：gpt-6.1-sol/high、CG-R：gpt-6-astra/xhigh、CG-T：gpt-6.1-sol/high。全体統括を含め同時4人。規則・保存・通信・共有制御・App・15辞書・catalogはChatGPT。**PR提出後の失敗・不具合・レビュー修正・コンフリクトは、作成者に関係なくすべてChatGPTが直接解消し、Claudeへ戻して待たない。** 提出後は描画ファイルも対象ロックを引き継いで修正できる。

全体計画IF01〜IF11/G0〜G6をそのまま使う。C0〜C4の再実装は行わず、未接続と旧条件の互換調整だけを追加する。Claudeの描画が必要な間も、契約確定、App/所有者/試験の準備、PR後問題の修正など独立した作業を進める。

## 今回の共有PR運用

CG00→CG01→CG02を先行実装し、最新main `52a6be5`からの専用ブランチ
`work/chatgpt-cg00-cg02-20261116`でドラフトPRを作る（予定#26、確定番号・URL・準備SHAは[受渡し票](../../acceptance/chameleol-handoff-ledger.md)）。通常起動はlegacy80のまま、CG02準備commitを開始点としてClaudeが同じPR・同じブランチへ予定されたCL工程を追加する。新しいPRを作らせない。受領後にCG03以降を同じPRで行い、最後の製品変更後に既存4組並行CIを完了させる。全体統合までマージしない。

先行PR後も予定された描画追加の担当は変更しない。失敗修正はCG04/CG07としてChatGPTが表示ファイルも直接修正する。対象だけ一時移管して同時編集を止め、変更前に最新ブランチを確認し、force pushしない。
