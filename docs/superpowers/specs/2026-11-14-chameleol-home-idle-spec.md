# ホームの連続色変化・巻きベロ仕様

作成日：2026-11-14（日本時間）。対象：`chameleonjp-lab/chameleol`。
確認基準：main `e3a74eb8f843eb2d608c9435ae9cb15e28c6b60a`（PR #16取り込み後）。

## 1. 目的と依頼の解釈

ホームのカメレオンが色を変え続け、時々巻きベロを伸縮させる。利用者の「実装計画書作成してPR」は、直前に提示した推奨案「24色を0.5秒ずつなめらかにつなぐ＋初回2〜3秒後、その後6〜10秒間隔の巻きベロ」を計画にする依頼として扱う。

常時の色変化と時々の巻きベロは利用者の要望。24色の具体値、巻きベロの各段階、動きを減らす設定での扱いは、下記の実装用の提案値である。今回のPRは文書のみで、実装・公開・実機合格を意味しない。

## 2. Approaches：比較した方式

| 方式 | 見え方・代償 | この計画での扱い |
| --- | --- | --- |
| 24色を0.5秒ごとに瞬時切替 | 色の区切りが明快だが、急な切替になる | 不採用 |
| 24色を0.5秒かけて隣の色へ連続変化 | 12秒で循環し、最終色から最初の色もつながる | 直前の推奨案として採用 |
| ランダム色を0.8〜1.2秒でつなぐ | 毎回異なるが、似た色の連続や明暗差の制御が要る | 不採用 |

巻きベロはホーム専用の曲がる舌を付ける。既存の直線状の舌を長くするだけでは「ほどける・巻く」が伝わらない。毎フレーム形状を作り直す方式ではなく、固定した頂点配列を更新する方式を採用する。

## 4. 確定する動作

### 色の変化

**HOME-01** ホーム模型が実際に表示された時を0msとし、常時なめらかに色を変える。新しくホームを作る時は元の緑から始める。待機時間や、色を止めて見せる時間は設けない。

**HOME-02** 次の24色を順に使う。各区間500ms、周期12000ms。隣り合う2色の8ビットRGBを0〜1へ変換し、その間を直線的につなぐ。計算途中で8ビットへ丸めない。既存の色管理設定を変更しない。これはホームの見せ方であり、ゲーム判定の色変換を流用・変更しない。

```text
#58c43c #7ac43c #9cc43c #bec43c #c4a83c #c4863c
#c4643c #c4423c #c43c58 #c43c7a #c43c9c #c43cbe
#a83cc4 #863cc4 #643cc4 #423cc4 #3c58c4 #3c7ac4
#3c9cc4 #3cbec4 #3cc4a8 #3cc486 #3cc464 #3cc442
```

元の緑の色相から15度ずつ逆順に並べ、元色の鮮やかさと最大RGB成分を揃えた提案パレット。見た目の明るさが全色で同一だとは扱わない。最終色から緑へも500msでつなぐ。0ms/12000msは `#58c43c`、250msは `#69c43c`、500msは `#7ac43c`。

**HOME-03** 体・頭・手足・尻尾は既存の共用体色を使う。目の外側は既存の明るい色味を維持して追従する。舌のピンク、目の渦、黒い輪郭、宝石を体色へ染めない。色変化の効果音は付けない。

### 巻きベロ

**HOME-04** 初回は表示中の累積時間で2000ms以上3000ms未満に1回。以後は前の動作が終わってから6000ms以上10000ms未満待ち、1回ずつ出す。ゲームの出題・装飾用の乱数を使わず、ホーム専用の乱数入力を使う。抽選は予約時の1回だけで、毎フレーム抽選しない。

**HOME-05** 1回900ms。段階の境界は次のとおり。実際の動物の生態を再現する仕様ではなく、このキャラクター用の巻きベロ表現である。

| 開始から | 段階 | 表示 |
| --- | --- | --- |
| 0〜150ms | 予備動作 | 口を少し開き、目を伸ばす方向へ向ける。巻いた先端を口元に見せる |
| 150〜300ms | 伸長 | 先端がほどけながら素早く伸びる |
| 300〜380ms | 最大長 | 一瞬だけ伸ばした状態を見せる |
| 380〜750ms | 収縮 | 伸ばす時よりゆっくり戻り、先端を巻き直す |
| 750〜900ms | 収納 | 巻いた先端を口へ収め、口・目・頭を元に戻す |

舌の基準半径0.05、最大の張り出し1.10、巻きの半径0.12、巻き数1.25をモデル座標の初期値とする。伸縮率・ほどけ率は0〜1。口元の始点は既存の `hero.tongue.position` を使い、頭の子として動かす。外へ伸ばした直線と先端の巻きがつながって見えることを合格条件とする。形状の細部は制作者が調整できるが、最終値と画像を実装証跡に残す。

**HOME-06** 頭は最大0.04ラジアンの小さい傾き、顎は元の位置から最大0.05だけ下げる動きを初期値とする。毎フレーム、基準姿勢から設定し、相対移動を足し続けない。舌は独立したピンクのまま。虫・的・捕食・追加ボタン・効果音は追加しない。

### 表示時間と片付け

**HOME-07** 色・首振り・舌は表示中の累積時間で進む。非表示中は描画予約を止め、戻った時に停止位置から再開する。画面が再描画されない時間を取り戻して舌を何回も出さない。期限を大幅に過ぎた予約は、次の描画で1回だけ開始する。

**HOME-08** ホーム以外へ移動したら、予約、表示変更の監視、サイズ監視、端末設定の監視、新しい形状をすべて片付ける。遅れて届いた描画やモデル読込で古いホームを復活させない。ホームを作り直した時は新しい一組だけが動く。保存・ランキング・本編・練習の時刻や状態に触れない。

**HOME-09** 端末の「動きを減らす」が有効なら、向き・目・頭・顎・舌の動作を止める。常時の体色変化は500ms区間の滑らかな変化として続ける。設定を途中で有効にしたら舌と姿勢を直ちに通常位置へ戻す。無効へ戻したら、その時から6000〜10000ms待って舌を再開し、過去の予約を再生しない。

**HOME-10** 402×700、402×874、874×402で、舌の最大長・巻き・頭・尻尾・輪郭が模型枠から欠けない。模型枠の大きさは変えず、最大姿勢を含む範囲からカメラ距離を決め、枠内側8CSS px以上の余白を確保する。動作中にカメラをズームさせない。回転・枠のサイズ変更時だけ再計算する。モデルが小さくなり過ぎないかは変更前後の画像でも確認する。

**HOME-11** ホームの描画予約は既存の1系統を維持する。新しい `setInterval` や演出ごとの描画ループは作らない。舌は長さ方向32分割・円周6分割の固定形状1個を本体と輪郭で共用し、頂点・法線用配列を再利用する。毎フレーム、新しい形状・材質・画像を作らない。借りたモデルの材質は舌側で解放せず、モデル自身に解放させる。

**HOME-12** 立体描画を使えない場合や作成途中の失敗でも、開始・練習・設定の操作を使えるようにする。新しい舌部品だけの作成に失敗した場合は色変化を残せるように片付ける。WebGL context lost時は予約を止め、復旧時は非表示復帰と同じく経過時間を加算しない。

## 5. 実装・確認の範囲

ホーム専用の演出として扱う。既存の演出80件・除外20件の番号や件数、採点規則v1〜v4、保存形式、初回ガイドの消費状態を変更しない。Node.js 20以上とThree.js 0.170.0を維持し、新しい実行時依存・音源・画像素材を追加しない。

自動検証は時刻境界・描画形状・表示切替・資源の片付けを確認する。iPhone 17 Pro Safariでは縦横、アドレスバー伸縮、別アプリ復帰、連続再表示、動きを減らす設定を確認する。自動ブラウザを実機合格として記録しない。既存成績を消すためのサイトデータ削除は手順へ入れない。
