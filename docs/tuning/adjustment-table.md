# 調整表（試作値と正式値）

2026年11月7日時点の記録です。ここに並べた数値は、すべて「試作値」です。iPhone の実機でまだ確かめていないため、正式値の欄は空けてあります。実機で測った後に、正式値・選んだ理由・適用する版を書き込みます。

採点や出題に関わる数値（判定規則）を正式値に変える時は、判定規則の版 `rulesVersion` か出題の版 `generatorVersion` を上げます。版を上げると、古い版で始めたプレイは古い版の規則のまま最後まで遊べて、結果もその版で受け付けます。新しい式で過去のスコアを計算し直すことはしません。保存や通信の数値（端末の動きだけに関わるもの）は、版を上げずに変えられます。
